# Using DeskDen

New configurations use Option-D to show/hide the launcher and Option-F to open the workbench. Existing configurations retain saved shortcuts and disabled choices. Configure these in Launcher and General settings respectively.

The brand and Settings → General → Software Update use the same lowercase `v` prefix for the installed version. The title-bar prefix is slightly smaller than the version digits, with subtle spacing and no separator dot. The shared title bar also keeps the selected city’s date, time and weather visible across modules. The upper-right controls minimize, toggle full screen/window mode and close the current interface. Closing keeps background services running. Use the upper-right **Quit DeskDen** power button and confirm to fully exit; in-flight work completes first.

- Home keeps disk capacity and runtime memory together in a compact summary: disk availability and its used-capacity bar, plus memory used/total, occupancy and independently measured pressure. Space Cleaning belongs to the disk actions. Separate cards show thermal/battery readings and realtime network speeds; each compact card opens its one destination from anywhere on its surface. The shorter summary leaves the day strip and schedule/reminder lists visible at the default window size. Larger compound workspaces retain their explicit internal actions. Missing readings remain unavailable. Date, time and weather now share the public title bar and one city setting, visible while browsing other modules. Without a city, date/time follow the system and weather offers an add-city state. Existing reminders keep their original due times; selecting a display city does not reschedule them.
- Device Status defaults to six hardware cards; network cards remain optional in the card library. Storage highlights available space with an explicitly used-capacity bar; memory highlights used memory and independently measured pressure. Disk capacities use decimal units and describe the startup volume, not the advertised size of the physical device. Available capacity follows the system estimate for important usage; details distinguish immediately free space from space macOS may reclaim. The estimate is not a list of safe-to-delete files or a guarantee of reclaimed space. Memory keeps its separate binary convention. Network Monitor groups live, daily and period traffic, with missing coverage shown explicitly.
- Space Cleaning is the file-cleanup destination, with ordinary cleanup and large-file scanning across global or custom locations. Open it from navigation, Home or storage details. Home uses actual memory readings instead of a separate assessment score; memory pressure remains independent of occupancy. See [Space Cleaning](space-cleaning.md) for default selections, protection, deletion methods and restoration. The former Health Center page and its assessment workflow have been removed. Process termination remains a separate explicit action in Device Status.
- Calendar and Reminders shares date-tile states and proportions with Home. Date and time fields use five editable choices for year, month, day, hour and minute; each supports typing and a menu. Month and year edits clamp the day to the actual month end. Wider windows expand both the calendar and its agenda/reminder column; narrow windows stack them. Use **接入系统** to connect the two separate macOS permissions and show existing Calendar events and Reminders lists. Once connected, new reminders default to the system's first writable list; choose another system list or explicitly keep a reminder only on this Mac in **保存到**. Existing local reminders remain intact and are never copied to the system automatically. Denied access keeps local content available. EventKit changes and returning to DeskDen refresh the existing system items; system events stay read-only and open in Calendar for editing. The reminder form uses shared editable date/time choices and notes with an overlay scrollbar that reserves no text width.
- Usage and Allowances (**用量与额度**) uses one responsive list of subscription, service-traffic and API-balance cards. Equal-width columns expand with the window and wrap below their minimum width; status dots, update information and whole-card detail entry remain. A category tag replaces collapsible groups. Manage custom categories, filter by category, or sort by addition time, name or category in either direction. Display settings never change source credentials or quota calculations. **配置用量** uses a connection-type selector for AI subscriptions, service traffic or API balances; it also manages category, name and icon. Codex/Claude plan information prefers the actual source; explicit user declarations are marked separately and never become metering history. An absent quota window is explained instead of drawn as a fake zero or blank meter. See [AI connections](ai-usage.md), [service traffic](provider-usage.md) and [DeepSeek API balances](api-balances.md). **Token 活动** retains the existing local activity and monthly summaries, with a concise source-share overview; detailed quotas and history remain in individual source details. A balance endpoint does not create Token activity, and local tokens never infer account quota or whole-account coverage.
- Private Space requires a separate password of at least eight characters, with no default or password recovery. It includes encrypted text formatting and category management. Touch ID is optional on supported Macs and builds with the required Apple-authorized signing profile; the password remains available. Navigation, close, idle and system protection events lock it. Copied or cut private text stays on this Mac's clipboard for up to three minutes and is cleared immediately on locking, provided a later copy has not replaced it. Backup restore validates first, confirms replacement and preserves the original encrypted copy.
- Appearance offers three mountain scenes, AR World and Thunder Cabin, plus surface opacity and ambient motion. New configurations default to Qingbi Morning Mist. Dialogs, choice lists and chart callouts share the card material and configured surface opacity; text and icons remain fully readable. Two minimal geometric icons update the running Dock, in-app branding and matching monochrome menu-bar mark, with Finder retaining the default installation icon. Motion stops in the background and respects Reduce Motion.

Hover feedback follows the control: actions and navigation use their own surfaces, detail arrows share an icon treatment, and text links stay lightweight. Home compact cards and AI quota card bodies retain their original surfaces without an added hover outline. Compact navigation cards activate across their whole surface; compound workspaces use their internal controls. Enabled actions keep the configured hand or arrow pointer and their full visible hit area.

The modular Mini shows date/time and weather independently in its header. Eight default cards show Codex and Claude quotas, the local traffic budget, disk, memory, one reminder, realtime network curves and thermal readings. Cards remain 220 pt wide and pack into fixed-height columns; the default panel is 748 × 292 pt. Its editor and Settings → General share card visibility, including optional service quota cards, all-hidden recovery and restore defaults. Layout editing supports dragging and keyboard ordering, while ordinary card clicks open the corresponding workbench page. Narrow displays paginate without rewriting the saved layout. See [Mini dashboard](mini-dashboard.md) for dimensions and data boundaries.

The Mini summary is temporary. It uses the same card tint and opacity with the content behind its window, without an opaque scene image. Moving the pointer away or pressing Escape dismisses it; no separate close button is needed. Expanding the full workbench from the top edge, menu, Dock or shortcut restores the same ordinary window and saved position. Clicking the workbench dismisses the transient launcher while preserving active editing and picker sessions. Launcher search matches Chinese, pinyin, English names, word initials and bounded fuzzy subsequences together.

Private Space reads encrypted payload formats 1 and 2 without rewriting them on password unlock. Saving an accepted document edit writes format 3, which preserves the expanded font choices, strikethrough, text colors and background highlights. Ordinary document saves retain the exact preceding encrypted revision; older readers reject format 3 rather than silently removing these styles. Before upgrading, export and separately retain an encrypted backup using the previous app's Protection and Backup page. Touch ID enrollment is an explicit protected-data write and still migrates original-format data before authentication; cancelling its system prompt may therefore leave the new format. Local ad-hoc preview builds do not carry the Apple-authorized application/Keychain signing capability required by Touch ID; password access remains available. See the [upgrade guide](install.md).

Changing the Private Space password also re-encrypts the automatic previous revision and app-managed restore histories that use the current password. Their historical contents are preserved; histories protected by a different password remain unchanged. Previously exported backups keep their original password. Preparation does not change files. Once replacement starts, a private recovery record containing only new-password ciphertext allows an interrupted change to finish on retry or next launch. Ordinary saves and restores stay blocked until it completes; then use the new password. No old-password rollback copy is created by this change.

Private clipboard entries carry confidential and temporary markers for cooperating clipboard tools and are excluded from Universal Clipboard. The three-minute deadline restarts on each private copy. Cleanup affects the current clipboard entry, not content already pasted elsewhere or retained independently by another application.

File, web, Shortcut and script bindings perform their configured action; review targets before saving. Denied system permissions do not prevent local-only features from working.
