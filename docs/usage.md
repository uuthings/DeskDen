# Using DeskDen

New configurations use Option-D to show/hide the launcher and Option-F to open the workbench. Existing configurations retain saved shortcuts and disabled choices. Configure these in Launcher and General settings respectively.

The launcher opens independently without bringing the workbench forward. Its settings and shortcut remain in Settings → Launcher; the main navigation no longer contains a launcher item. Hovering a key gently lifts and enlarges its frame and icon while the label and click region stay fixed. Reduce Motion uses a static highlight instead.

The installed version appears beside DeskDen at the upper left and in Settings → General → Software Update, using a lowercase `v` prefix. Top navigation opens each module at its root; internal detail links retain their destination and unsaved editors keep their navigation protection. The upper-right controls switch appearance, open settings, identify the local macOS account and close the workbench. Closing keeps background services running. Use the macOS application or menu-bar menu to quit DeskDen; confirmation and pending-work protections still apply.

- Home places this Mac's device, temperature, fan, power and memory information at the upper left, the month calendar at the upper right, and the greeting, time, date and weather between them. Storage, live network traffic and pending items form a compact lower row. Selecting a date reveals its arrangements below the calendar without opening a popup. Reminder completion remains available directly in the list. Missing readings remain unavailable. The city setting controls displayed time and weather; selecting a city does not reschedule existing reminders. See [Home and navigation](home-interface.md) for the shared layout and interaction rules.
- Device Status defaults to six hardware cards; network cards remain optional in the card library. Storage shows used space and its used-capacity bar, with available space alongside; memory highlights used memory and independently measured pressure. Disk capacities use decimal units and describe the startup volume, not the advertised size of the physical device. Available capacity follows the system estimate for important usage; details distinguish immediately free space from space macOS may reclaim. The estimate is not a list of safe-to-delete files or a guarantee of reclaimed space. Memory keeps its separate binary convention. Network Monitor groups live, daily and period traffic, with missing coverage shown explicitly.
- Space Cleaning offers ordinary cleanup and large-file scanning across global or custom locations. Its preparation page separates used, immediately free and system-reclaimable capacity, then lets you choose the scan mode and locations. Scanning has its own progress page; results use a list with a collapsible details pane. Searchable cleanup history retains item names, paths, sizes and outcomes. Open it from navigation, Home, the Mini disk card or storage details. See [Space Cleaning](space-cleaning.md) for default selections, protection, deletion methods and restoration. Process termination remains a separate explicit action in Device Status.
- Calendar and Reminders places the month and the selected day's complete arrangements on the left, with the next seven days above undated reminders on the right. The source filter applies to the right-hand lists; selecting a day always shows all of that day's events and reminders, including completed reminders. Purple event cards show time, duration and calendar; green reminder cards can be completed and undone. Events remain read-only and open in Calendar for editing. Wider windows use a 45/55 split with bounded date cells; narrow windows stack the four sections. Use **接入系统** to connect the two separate macOS permissions. New reminders then default to the first writable system list; **保存到** can select another list or this Mac only. Existing local reminders stay intact and are not copied automatically. Denied access keeps local content available, and EventKit changes or returning to DeskDen refresh system items.
- New reminders offer **无期限**, **指定日期** and **指定天数**. A day count is converted to a fixed due date when saved; it does not move forward on later days. Counting starts tomorrow. The settings button beside the number selects every day or Monday–Friday, whether to skip published mainland-China holidays, and whether to include official makeup workdays. A rule requiring holiday data cannot be saved beyond the available official calendar; it never silently assumes unknown holidays. The calculated due date is shown before saving. Year, month, day, hour and minute choices support both typing and menus; changing the month or year clamps to its valid last day. Notes start at two lines, grow to six and then scroll internally. Selecting a display city does not reschedule existing reminders.
- Usage and Allowances (**用量与额度**) uses one responsive list of subscription, service-traffic and API-balance cards. Equal-width columns expand with the window and wrap below their minimum width; status dots, update information and whole-card detail entry remain. Each header pairs a 32-point icon with a title and smaller subtitle. The category tag follows the title on the same line, with a subtle category-colored fill and border. Manage custom categories, filter by category, or sort by addition time, name or category in either direction. Display settings never change source credentials or quota calculations. **配置用量** uses a connection-type selector for AI subscriptions, service traffic or API balances; it also manages category, name and icon. Codex/Claude plan information prefers the actual source; explicit user declarations are marked separately and never become metering history. An absent quota window is explained instead of drawn as a fake zero or blank meter. Service traffic shows the used percentage alongside consumed and total allowance. See [AI connections](ai-usage.md), [service traffic](provider-usage.md) and [DeepSeek API balances](api-balances.md). **Token 活动** retains the existing local activity and monthly summaries, with a concise source-share overview; detailed quotas and history remain in individual source details. A balance endpoint does not create Token activity, and local tokens never infer account quota or whole-account coverage.
- New Private Space passwords require at least six characters. An optional local hint appears below the password field when you click its question mark or after three consecutive failed password checks. Touch ID is available on supported Macs and builds with the required Apple-authorized signing profile. After enrollment, DeskDen asks whether to make Touch ID the default. With that default, entering the locked Private Space in the active workbench requests Touch ID once. The locked page offers manual retry and password unlock. Navigation away, close, idle and system protection events lock Private Space. Copied or cut private text is cleared at lock or after three minutes if it is still the current clipboard entry. Unlock Private Space to open Protection and Backup, change settings, export a backup or restore over existing data. On confirmation, DeskDen preserves an encrypted copy of the displaced space. First-time setup also offers backup recovery. Both recovery paths verify the password used when the backup was exported.
- Appearance pairs a cyan-and-amber background with milky translucent cards in light mode, and ink-and-gold artwork with charcoal glass in dark mode. The header switch and appearance settings share the saved preference, which can also follow macOS. Cards, dialogs, menus and Mini share the same materials and semantic colors. Theme changes crossfade while the switch icon turns; reduced motion disables animation. Previous theme and opacity settings remain readable for compatibility but are no longer offered as visual variants.

Consumed-quota and occupied-capacity meters share one visual rule across the workbench, Mini and desktop widgets: the normal theme color below 70%, yellow from 70% and red from 90%. Integer percentage labels round down, while the fill and color use the unrounded reading. Configured notification thresholds remain independent. Unknown readings are not replaced with zero; values above 100% retain their reported number while the meter fills to its limit. Memory uses measured pressure, battery charge uses low-charge states, and download or scan completion is not treated as consumed quota.

Quota cards show the remaining days and hours until a known reset, or hours and minutes below 24 hours. Last-observation labels show elapsed time rather than a clock time. Details retain exact dates and times in the selected workbench timezone, including its city or location label and GMT offset, and show the source timezone when explicitly supplied. An unspecified source timezone stays unknown; a provider's date-only value remains unconverted without a countdown. Passing a reset time preserves the last reading while awaiting new source data.

Buttons and selectors share stable sizing and border colors; hover changes their fill without shrinking them. Top navigation expands the active or hovered label, and cards keep their position during hover. Compact navigation cards activate across their whole surface; compound workspaces use their internal controls. Enabled actions keep the configured hand or arrow pointer and their full visible hit area.

The modular Mini shows date/time and weather independently in its header. Seven default cards place realtime network and thermal readings in the first column, disk/memory/reminder in the second, and Codex/Claude quotas in the third. Configured service cards can follow; the local traffic-budget card is optional. Cards remain 220 pt wide, with up to four visible columns before pagination. Its editor and Settings → General share visibility, all-hidden recovery and restore defaults. Drag the whole card or use keyboard ordering in edit mode; ordinary clicks open the corresponding workbench page. The network curve updates without first opening Network Monitor. See [Mini dashboard](mini-dashboard.md) for dimensions and data boundaries.

The Mini summary is temporary. It uses the same card tint and opacity with the content behind its window, without an opaque scene image. Moving the pointer away or pressing Escape dismisses it; no separate close button is needed. Expanding the full workbench from the top edge, menu, Dock or shortcut restores the same ordinary window and saved position. Clicking the workbench dismisses the transient launcher while preserving active editing and picker sessions. Launcher search matches Chinese, pinyin, English names, word initials and bounded fuzzy subsequences together.

Private Space reads encrypted payload formats 1 and 2 without rewriting them on password unlock. Saving an accepted document edit writes format 3, which preserves the expanded font choices, strikethrough, text colors and background highlights. Ordinary document saves retain the exact preceding encrypted revision; older readers reject format 3 rather than silently removing these styles. Before upgrading, export and separately retain an encrypted backup using the previous app's Protection and Backup page. Touch ID enrollment is an explicit protected-data write and still migrates original-format data before authentication; cancelling its system prompt may therefore leave the new format. Local ad-hoc preview builds do not carry the Apple-authorized application/Keychain signing capability required by Touch ID; password access remains available. See the [upgrade guide](install.md).

Changing the Private Space password also re-encrypts the automatic previous revision and app-managed restore histories that use the current password. Their historical contents are preserved; histories protected by a different password remain unchanged. Previously exported backups keep their original password. Preparation does not change files. Once replacement starts, a private recovery record containing only new-password ciphertext allows an interrupted change to finish on retry or next launch. Ordinary saves and restores stay blocked until it completes; then use the new password. No old-password rollback copy is created by this change.

Private clipboard entries carry confidential and temporary markers for cooperating clipboard tools and are excluded from Universal Clipboard. The three-minute deadline restarts on each private copy. Cleanup affects the current clipboard entry, not content already pasted elsewhere or retained independently by another application.

File, web, Shortcut and script bindings perform their configured action; review targets before saving. Denied system permissions do not prevent local-only features from working.

Calendar source switches show a pending authorization state and only appear enabled when access is actually granted. A rejected, restricted or failed calendar/reminder request opens a clear explanation, including in source management. **前往系统设置** opens the corresponding privacy pane; if macOS cannot open it, the dialog gives a manual path. Returning to DeskDen refreshes the actual permissions. Calendar and Reminders are separate permissions; failing one does not disconnect the other or move local data. Connected system-calendar lists start collapsed and can be expanded to manage individual calendars.
