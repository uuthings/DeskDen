# Using Fangcun

New configurations use Option-D to show/hide the launcher and Option-F to open the workbench. Existing configurations retain saved shortcuts and disabled choices. Configure these in Launcher and General settings respectively.

The upper-right controls minimize, toggle full screen/window mode and close the current interface. Closing keeps background services running. Confirm **Quit Fangcun** in the Fangcun menu to fully exit; in-flight work completes first.

- Home shows health, device summaries, calendar/reminders, weather, date, time and time zone. Complete reminders directly and undo them.
- Device Status defaults to six hardware cards; network cards remain optional in the card library. Storage highlights available space with an explicitly used-capacity bar; memory highlights used memory and independently measured pressure. Network Monitor groups live, daily and period traffic, with missing coverage shown explicitly.
- Health Center is an independent navigation destination. Each status card shows its current deduction, no deduction, or unavailable assessment; battery health does not affect the score. Scoring details open from the corresponding card and use the same rules as the assessment. Space Cleaning has its own global or custom scan and does not replace the health report. See [Space Cleaning](space-cleaning.md) for default selections, protection, deletion methods and restoration. Application exits still require explicit selection and confirmation.
- Calendar and Reminders shares date-tile states and proportions with Home. Wider windows expand both the calendar and its agenda/reminder column; narrow windows stack them. It supports local data and optional system sources. Local reminders do not require calendar permissions. System events are read-only; reminder writes depend on granted access and list permissions.
- AI Usage distinguishes provider quotas, local Token activity, imported/manual readings and estimates. Only source-provided quota periods and membership metadata are shown; absent windows or unknown plan multipliers are not inferred. Provider details show the last 31 local calendar days as daily square heatmaps, separately for each observed quota window. Each day uses its last valid observed percentage, with no-reading days distinguished from 0%; snapshots are never summed into daily usage.
- Private Space requires a separate password of at least eight characters, with no default or password recovery. It includes encrypted text formatting and category management. Touch ID is optional on supported Macs and builds with the required Apple-authorized signing profile; the password remains available. Navigation, close, idle and system protection events lock it. Backup restore validates first, confirms replacement and preserves the original encrypted copy.
- Appearance offers three mountain scenes, AR World and Thunder Cabin, plus surface opacity and ambient motion. New configurations default to Qingbi Morning Mist. The three matching rounded-square water-mirror icons update the running Dock and in-app branding, with Finder retaining the default installation icon. Motion stops in the background and respects Reduce Motion.

Hover feedback follows the control: actions and navigation use their own surfaces, detail arrows share an icon treatment, and text links stay lightweight. Home storage/memory readouts and AI quota card bodies retain their original surfaces without an added hover outline. Enabled actions keep the configured hand or arrow pointer and their full visible hit area.

The Mini summary is temporary. Expanding the full workbench from the top edge, menu, Dock or shortcut restores the same ordinary window and saved position. Clicking the workbench dismisses the transient launcher while preserving active editing and picker sessions. Launcher search matches Chinese, pinyin, English names, word initials and bounded fuzzy subsequences together.

Private Space can read the original encrypted format without rewriting it on a read-only password unlock. Saving changes or starting Touch ID enrollment upgrades the encrypted contents to format 2; migration precedes the system authentication prompt, so cancelling that prompt may still leave format 2. The original notarized 0.1.0 app intentionally refuses that newer format; use the newer app for further access. Before upgrading an original-format vault, export and separately retain an encrypted backup from the old app's Protection and Backup page. Later local candidates that already support format 2 do not need a second migration. See the [upgrade guide](install.md).

File, web, Shortcut and script bindings perform their configured action; review targets before saving. Denied system permissions do not prevent local-only features from working.
