# Using Fangcun

New configurations use Option-D to show/hide the launcher and Option-F to open the workbench. Existing configurations retain saved shortcuts and disabled choices. Configure these in Launcher and General settings respectively.

The upper-right controls minimize, toggle full screen/window mode and close the current interface. Closing keeps background services running. Use the upper-right **Quit Fangcun** power button and confirm to fully exit; in-flight work completes first.

- Home shows health, device summaries, calendar/reminders, weather, date, time and time zone. Complete reminders directly and undo them. Selecting either weather or the clock opens one **City, Weather and Time** form. Choose a city, °C or °F, time zone and clock format, then save them together. The display clock follows the selected city by default; an explicit system or custom time zone remains available. Existing custom zones are preserved, and no city is inferred from a time zone. Without a selected city, the linked clock uses the system zone. These display preferences do not change reminder due times or notification zones. Temperature readings always show their unit; unavailable and stale weather remain explicit.
- Device Status defaults to six hardware cards; network cards remain optional in the card library. Storage highlights available space with an explicitly used-capacity bar; memory highlights used memory and independently measured pressure. Disk capacities use decimal units and describe the startup volume, not the advertised size of the physical device. Available capacity follows the system estimate for important usage; details distinguish immediately free space from space macOS may reclaim. The estimate is not a list of safe-to-delete files or a guarantee of reclaimed space. Memory keeps its separate binary convention. Network Monitor groups live, daily and period traffic, with missing coverage shown explicitly.
- Health Center is an independent navigation destination. Each status card shows its current deduction, no deduction, or unavailable assessment; battery health does not affect the score. Scoring details open from the corresponding card and use the same rules as the assessment. Space Cleaning has its own global or custom scan and does not replace the health report. See [Space Cleaning](space-cleaning.md) for default selections, protection, deletion methods and restoration. Application exits still require explicit selection and confirmation.
- Calendar and Reminders shares date-tile states and proportions with Home. Wider windows expand both the calendar and its agenda/reminder column; narrow windows stack them. It supports local data and optional system sources. Local reminders do not require calendar permissions. System events are read-only; reminder writes depend on granted access and list permissions.
- AI Usage distinguishes provider quotas, local Token activity, imported/manual readings and estimates. Only source-provided quota periods and membership metadata are shown; absent windows or unknown plan multipliers are not inferred. Provider details show aligned daily bars for the last 31 local days: one percentage plot for each observed quota window and a separate local Token plot. A quota bar is the last valid observed percentage that day, not that day’s consumption; resets may lower it. Daily Token totals include deduplicated input, output and cache records from connected local sources. Selecting a day shows both units, with missing records distinguished from a measured zero. Token counts never infer account quota or whole-account coverage.
- Private Space requires a separate password of at least eight characters, with no default or password recovery. It includes encrypted text formatting and category management. Touch ID is optional on supported Macs and builds with the required Apple-authorized signing profile; the password remains available. Navigation, close, idle and system protection events lock it. Backup restore validates first, confirms replacement and preserves the original encrypted copy.
- Appearance offers three mountain scenes, AR World and Thunder Cabin, plus surface opacity and ambient motion. New configurations default to Qingbi Morning Mist. Dialogs, choice lists and chart callouts share the card material and configured surface opacity; text and icons remain fully readable. Two minimal geometric icons update the running Dock, in-app branding and matching monochrome menu-bar mark, with Finder retaining the default installation icon. Motion stops in the background and respects Reduce Motion.

Hover feedback follows the control: actions and navigation use their own surfaces, detail arrows share an icon treatment, and text links stay lightweight. Home storage/memory readouts and AI quota card bodies retain their original surfaces without an added hover outline. Enabled actions keep the configured hand or arrow pointer and their full visible hit area.

The Mini summary combines the selected clock, city and weather, the next calendar event and reminder, live device readings, and Codex/Claude quota windows. Its configuration button and Settings → General share four persistent visibility choices, including an all-hidden state and restore-default action. The compact panel keeps a fixed information-row height and pages its contents on narrow displays. Calendar results cover the next seven days; missing or expired readings remain clearly marked.

The Mini summary is temporary. It uses the same card tint and opacity with the content behind its window, without an opaque scene image. Moving the pointer away or pressing Escape dismisses it; no separate close button is needed. Expanding the full workbench from the top edge, menu, Dock or shortcut restores the same ordinary window and saved position. Clicking the workbench dismisses the transient launcher while preserving active editing and picker sessions. Launcher search matches Chinese, pinyin, English names, word initials and bounded fuzzy subsequences together.

Private Space reads encrypted payload formats 1 and 2 without rewriting them on password unlock. Saving an accepted document edit writes format 3, which preserves the expanded font choices, strikethrough, text colors and background highlights. The exact preceding encrypted revision is retained before replacement; older readers reject format 3 rather than silently removing these styles. Before upgrading, export and separately retain an encrypted backup using the previous app's Protection and Backup page. Touch ID enrollment is an explicit protected-data write and still migrates original-format data before authentication; cancelling its system prompt may therefore leave the new format. Local ad-hoc preview builds do not carry the Apple-authorized application/Keychain signing capability required by Touch ID; password access remains available. See the [upgrade guide](install.md).

File, web, Shortcut and script bindings perform their configured action; review targets before saving. Denied system permissions do not prevent local-only features from working.
