# Home and navigation

The home page uses a cyan-and-amber background, light translucent cards, and a centered top navigation bar. Only the active destination expands its label by default; hovering or keyboard-focusing another destination reveals the same white capsule treatment. Card hover feedback changes the surface without moving its position.

The desktop layout places the device summary at the upper left, an independent month calendar at the upper right, and the greeting, clock, date, and weather between them. Storage, live network traffic, and pending items share the lower row. Cards use 14-point content insets. The page reflows at smaller widths instead of scaling the typography.

Data remains connected to the existing device, calendar, weather, and cleanup services. Storage uses actual capacity readings rather than fabricated application or document categories. Reclaimable storage is an operating-system estimate; cleanup recommendations are available only after a scan and are not treated as guaranteed recoverable space. Network readings and the recent trend cover all local traffic.

Calendar selection reveals that day's actual events and reminders. It does not remove unrelated pending items from the home list. Events remain read-only; reminders retain completion, editing, and undo. Reminder colors distinguish known source types because custom source colors are not currently supplied by the data model.

The brand menu contains window commands, the version, update access, and explicit application quit. The account button shows the current local account; it does not imply an online sign-in service. Existing modules retain their content layouts while sharing the new navigation.
