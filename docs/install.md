# 安装与升级

方寸要求 **macOS 14 或更高版本**。正式下载包同时包含 Apple Silicon 与 Intel 架构；目前真实运行验证使用 Apple Silicon Mac，Intel 与较早系统尚未完成逐项实机验证。

## 首次安装

1. 从 [v0.2.0 Release](https://github.com/uuthings/DeskDen/releases/tag/v0.2.0) 下载 `Fangcun-0.2.0-macos-universal.zip`。`Source code` 压缩包是源码，不是安装包。
2. 解压后将「方寸.app」放入「应用程序」，再打开 App。发布包使用 Developer ID 签名并按 Xcode Organizer 流程公证；系统首次打开时仍可能要求确认。
3. 新配置默认使用 `⌥ D` 呼出启动器，`⌥ F` 打开工作台。也可以从状态栏或顶部入口进入。关闭窗口仅收起界面，后台继续运行；彻底退出通过方寸菜单确认。

日历、提醒事项与通知按功能请求权限，拒绝授权不影响本机功能。私密空间需要自设独立密码，没有预设密码或密码找回功能。可在支持 Touch ID 的 Mac 上主动开启指纹解锁，密码解锁继续可用。更多说明见 [使用指南](usage.md)。

## 从本地旧版升级

最初的 0.1.0 没有更新器，需要手动安装 0.2.0 一次：先从方寸菜单正常退出旧 App，再替换「应用程序」中的 App。设置、快捷键和资料保存在 App 之外，替换 App 不会主动删除它们。不要同时运行同 Bundle ID 的多个副本。

若曾使用最初已公证的 0.1.0 私密空间，先在旧 App「保护与备份」中导出加密备份并另行保存。新版可以读取旧格式，只读密码解锁不会改写资料；实际保存资料或发起 Touch ID 开启后会写入格式 2，Touch ID 的系统验证即使取消也可能已完成迁移。旧 0.1.0 无法读取格式 2，迁移后继续使用新版。已经支持格式 2 的本地精校候选无需再次迁移。

## 后续更新

在「设置 → 通用 → 软件更新」点击「检查更新」，也可从方寸菜单检查。默认采用手动模式，可自行开启每日自动检查；不会静默下载或安装，安装由用户确认。更新检查失败会显示错误，不会当作「已是最新版本」。

## 校验下载

从同一 Release 下载 `SHA256SUMS.txt`，在下载目录执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

校验值确认文件与清单一致，不单独证明来源。App 的系统签名与公证检查仍应保留；不要通过移除隔离标记或停用 Gatekeeper 绕过系统检查。如下载失败或签名提示异常，请通过 [Issues](https://github.com/uuthings/DeskDen/issues) 反馈。

## 卸载

先从方寸菜单彻底退出，再移除「应用程序」中的 App。移除 App 不会自动删除私密资料、加密备份和用户设置；保留需要的数据后再自行管理。
