# 方寸 · DeskDen

常用之物，皆在方寸之间。方寸是一款原生 macOS 应用，把启动器、设备信息、空间清理、日历与提醒、用量与额度和私密资料放进同一个界面。

当前版本为 **0.3.0**。正式 App 与校验文件见 [v0.3.0 Release](https://github.com/uuthings/DeskDen/releases/tag/v0.3.0)，首次安装与本地旧版升级请先阅读 [安装指南](docs/install.md)。GitHub 的源码压缩包不能直接作为 App 安装。

## 主要功能

- 启动器：应用搜索、键位绑定，以及文件、网页、快捷指令和脚本入口。
- 设备与空间清理：真实硬件读数、普通清理与大文件扫描；核对文件用途并确认后处理，保护开发依赖和正式归档。
- 日历与提醒：本机提醒，以及授权后接入的系统日历与提醒事项。
- 用量与额度：独立 AI 和服务流量卡片，支持 Codex、Claude、IPRoyal 与搬瓦工；本机 Token 记录归入 AI 分类。网络监控保留实时网速与单独的周期预算。
- 私密空间：独立密码加密、自动锁定、加密备份、文字格式与完整分类管理；正确签名授权的构建可选用 Touch ID。
- 外观与桌面组件：青碧晨雾、月白云海、暖霞悬山、AR 世界与雷霆机舱主题，以及界面不透明度和组件管理。
- 图标选择：在「设置 → 外观与材质」中选择青碧晨雾、月白云海或暖霞悬山，默认使用青碧晨雾。
- 软件更新：默认手动检查，可选择每日自动检查；下载与安装仍需确认。

工作台显示时提供程序坞与应用切换入口；关闭界面后继续后台运行，可从状态栏或快捷键重新打开。最小化与关闭分别处理；顶栏与侧栏尺度保持一致，内容随窗口空间重排。

## 要求与构建

App 最低运行系统为 macOS 14；从源码构建需要 **Xcode 27.0（Swift 6.4）或兼容的新版本**。当前正式构建与 CI 固定使用 Xcode 27.0，运行验证环境为 Apple Silicon，其他硬件与较早系统需单独验证。工程使用系统框架、本地 Swift Package，以及固定版本的 Sparkle 2.10.0 更新框架；初次构建需要联网解析依赖。

打开 `Fangcun.xcodeproj`，选择 `Fangcun` scheme 和当前 Mac。命令行与验证说明见 [开发指南](Launcher/README.md)；正式分发遵循 [发布流程](docs/releasing.md)。

## 使用与数据

关闭窗口只收起界面，后台服务继续运行；彻底退出通过方寸菜单确认。新配置默认使用 `⌥ D` 呼出启动器，`⌥ F` 打开工作台，已有配置保留保存的快捷键。顶部、菜单、程序坞与快捷键进入同一个工作台窗口。

系统日历、提醒事项与通知按功能请求权限。本机提醒无需系统日历授权。无有效来源的项目显示不可用；本机 Token 记录不等同于服务商额度。私密空间没有预设密码或密码找回功能，请妥善保存密码和加密备份。
