# 方寸山应用图标

本目录保存用户于 2026-10-22 确认纳入 App 的三幅原始位图：青碧晨雾、月白云海、暖霞悬山。原图逐字节保留；其来源、生成提示词、尺寸和指纹见 `provenance.json`。未采用的探索稿不作为正式图标资源。

在仓库根目录运行：

```sh
swift Launcher/scripts/prepare-app-icons.swift
```

转换脚本只进行透明画布上的等比例缩放与居中，不裁切、不拉伸，也不修改画面。暖霞悬山原图略高于宽，保持原比例置入正方形，避免水滴变形。三个生产 ICNS 文件各包含 16–1024 像素的完整标准表示；`Resources/AppIcon.icns` 与默认的青碧晨雾相同。

设置中的应用图标选择保存在本机偏好中，启动时恢复，并通过 AppKit 更新运行中的程序坞与应用切换器图标。不会向已签名的 App 包写入资源；访达和安装包中的固定图标为默认的青碧晨雾。
